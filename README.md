# Project AI Forecast

Десктопное приложение для прогнозирования **стоимости проекта, сроков выполнения и уровня риска** с использованием искусственной нейронной сети, реализованной самостоятельно на Python.

Программа анализирует данные исторических проектов и формирует прогноз для нового проекта на основании его площади, стоимости материалов и уровня сложности.

---

## О проекте

**Project AI Forecast** — учебный программный проект, демонстрирующий практическое применение искусственных нейронных сетей для многопараметрического прогнозирования.

В отличие от решений, использующих готовые библиотеки машинного обучения, нейронная сеть в данном проекте реализована вручную на Python.

В программном коде самостоятельно реализованы:

- прямое распространение сигнала;
- функция активации Sigmoid;
- обратное распространение ошибки;
- корректировка весов и смещений;
- нормализация входных и выходных данных;
- обучение и тестирование нейронной сети.

Приложение имеет графический интерфейс, позволяющий обучать модель, вводить параметры нового проекта, получать прогноз и работать с историческими данными.

## Архитектура нейронной сети

В приложении используется полносвязная нейронная сеть прямого распространения следующей архитектуры:

```text
Входной слой
3 параметра
     │
     ▼
Скрытый слой 1
10 нейронов
     │
     ▼
Скрытый слой 2
8 нейронов
     │
     ▼
Выходной слой
3 параметра
```

Кратко архитектуру можно представить следующим образом:

```text
3 → 10 → 8 → 3
```

---

## Входные параметры

Нейронная сеть получает три параметра нового проекта:

1. **Площадь проекта**
2. **Стоимость материалов**
3. **Сложность проекта**

Перед передачей в нейронную сеть значения нормализуются.

---

## Выходные параметры

После обработки входных данных нейронная сеть одновременно прогнозирует три значения:

1. **Итоговую стоимость проекта**
2. **Продолжительность выполнения проекта**
3. **Уровень риска**

После получения результата выполняется обратное преобразование нормализованных значений в реальные величины.

---

## Обучение нейронной сети

Для обучения используется алгоритм **обратного распространения ошибки — Backpropagation**.

Основные параметры обучения:

- количество эпох: `10 000`;
- коэффициент обучения: `0.5`;
- обучающая выборка: около `80 %`;
- тестовая выборка: около `20 %`;
- функция активации: `Sigmoid`.

Перед началом обучения исходные данные нормализуются в диапазон от `0` до `1`.

На каждой эпохе выполняется:

```text
Входные данные
      ↓
Прямое распространение
      ↓
Получение прогноза
      ↓
Расчёт ошибки
      ↓
Обратное распространение ошибки
      ↓
Обновление весов и смещений
```

## Оценка качества модели

После завершения обучения качество нейронной сети оценивается на тестовой части данных.

В программе рассчитываются следующие метрики:

### MSE

**Mean Squared Error — среднеквадратичная ошибка.**

Показывает среднее значение квадратов ошибок между реальными и прогнозируемыми значениями.

Чем меньше значение MSE, тем выше точность модели.

### MAE

**Mean Absolute Error — средняя абсолютная ошибка.**

Показывает среднюю абсолютную величину отклонения прогнозов от реальных значений.

### R²

**Коэффициент детерминации.**

Показывает, насколько хорошо модель объясняет изменение исходных данных.

Чем ближе значение R² к `1`, тем лучше модель описывает имеющиеся данные.

## Исторические данные

Для первоначального обучения в программе используется набор исторических проектов.

Каждая запись содержит:

```text
Площадь
Стоимость материалов
Сложность проекта
Фактическая стоимость
Фактический срок
Фактический риск
```

Пользователь может самостоятельно добавлять новые исторические проекты через интерфейс приложения.

После добавления новых данных модель можно переобучить.

Исторические данные сохраняются в файле:

```text
projects.json
```

## Прогнозирование проекта

Для получения прогноза пользователь вводит:

```text
Площадь проекта
Стоимость материалов
Сложность проекта
```

После обработки данных нейронная сеть выводит:

```text
Прогнозируемую стоимость
Прогнозируемый срок
Уровень риска
```

Дополнительно программа рассчитывает рекомендуемый резерв бюджета и времени.

---

## Анализ риска

В зависимости от прогнозируемого значения риска проект относится к одной из трёх категорий.

### Низкий риск

```text
Риск < 30 %
```

Проект имеет относительно стабильные прогнозные показатели.

### Средний риск

```text
30 % ≤ Риск < 60 %
```

Рекомендуется предусмотреть дополнительный резерв бюджета и времени.

### Высокий риск

```text
Риск ≥ 60 %
```

Рекомендуется увеличить резерв ресурсов и более тщательно контролировать реализацию проекта.

## Графический интерфейс

Интерфейс программы реализован с использованием библиотеки **Tkinter**.

Приложение содержит три основных раздела:

### Прогноз

Используется для ввода характеристик нового проекта и получения результатов работы нейронной сети.

### История проектов

Позволяет просматривать обучающие данные, добавлять новые проекты и удалять существующие записи.

### Нейросеть

Содержит информацию об архитектуре модели и результатах оценки её качества.

В интерфейсе отображаются:

- архитектура сети;
- количество эпох;
- количество скрытых слоёв;
- количество нейронов;
- MSE;
- MAE;
- R².
